# Credit attribution — ручная разметка

## Контекст

Нужно понимать какие позиции профинансированы заёмными средствами, чтобы
видеть реальный risk picture (свой капитал vs кредитный).

## История подходов

### Попытка 1 — USD-pool FIFO (отброшена)
Один USD-пул на кошелёк. `borrow` добавляет, `lp_add`/`lend_supply` тратит.
**Проблема:** игнорирует токены. Если занял USDT, потом положил собственный
WBTC в lending — алгоритм атрибутировал WBTC деп как кредитный.

### Попытка 2 — token-taint с ratio (отброшена)
Per-token `balance` и `tainted`. Каждый spend списывает taint
пропорционально ratio.
**Проблемы:**
- 200+ строк, сложно отлаживать
- Mixed balance даёт «91%/94%» а не «100%»
- Negative balance из unknown pre-history ломает tracking
- Депозит-пары (GMX V2 lp_add → lp_remove с GM-token) ломают логику

### Попытка 3 — credit-only FIFO (отброшена)
Только `creditBalance` per token, без full balance. Спенды забирают credit
first.
**Проблема:** всё равно сложен, ошибается в edge cases swap-цепочек,
нужны heuristics для деп-пар. Точность 97% вместо 100% из-за gas-капель.

### Финальное решение — ручная разметка

Алгоритмическая атрибуция убрана. Пользователь сам помечает позиции
чекбоксом в строке таблицы.

## Реализация

`apps/web/src/lib/portfolio/credit_overrides.ts`:
- Хук `useCreditOverrides()` поверх `useLocalStorage`
- Ключ `${walletId}|${chain}|${protocolId}|${sortedSymbols}` —
  стабилен между загрузками
- Map<key, true>

`OpenPositionsPage`:
- Чекбокс рядом с ID каждой позиции
- При отметке: `creditFundedUsd = currentUsd` (вся позиция кредитная)
- Бейдж `credit` в строке
- В шапке `Свой капитал` / `Кредитный капитал` обновляются

## Преимущества

- Простота — нет хитрого алгоритма
- 100% точность — пользователь знает свои позиции лучше чем эвристика
- Стабильно — не ломается на новых паттернах протоколов
- Persistent через сессии (localStorage)

## Когда вернуться к авто

Когда появится много позиций (10+) и ручной toggle станет утомительным.
К тому моменту можно будет добавить **подсказки** из FIFO алгоритма
(«мы думаем что эта позиция кредитная, отметить?») — но как hint, не как
истину.
