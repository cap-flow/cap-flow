# Capflow — заметки

Vault для совместной работы с Claude. Здесь лежат план, решения, термины и
заметки про подключенные протоколы.

## Структура

- [[ROADMAP]] — что сделано и что в очереди
- [[GLOSSARY]] — термины проекта (HF, IL, Pa/Pb, P_break, …)
- `decisions/` — архитектурные решения по фичам
- `protocols/` — заметки по конкретным DeFi-протоколам (Aave, Morpho, Fluid, …)

## Workflow

Claude может читать/писать любые `.md` в этой папке:
- При обсуждении новой фичи — пишем краткую запись в `decisions/`
- При интеграции нового протокола — заметку в `protocols/`
- Текущий план задач — в [[ROADMAP]]

## Соглашения

- Файлы в нижнем регистре с дефисами: `v3-popup.md`
- Wiki-links для связности: `[[ROADMAP]]`, `[[decisions/credit-attribution]]`
- Дата в frontmatter формата `2026-05-04`
