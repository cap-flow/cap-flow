## Ключевые архитектурные решения

1. **`raw` JSONB column** — full `ClassifiedOp` сохраняется как frozen snapshot. Re-classify не теряет данные.
2. **Idempotent upsert через `(wallet, tx_hash, log_index)`** — re-sync безопасен, no dedup logic нужна.
3. **Composite frontend id parsing** — `api:<walletId>:<addressId>` → real walletId для server-side scope queries.
4. **L1 + L2 merge с дедупом по hashes** — server pairs (deterministic) идут первыми, client heuristic fallback'ом.
5. **Annotation upsert by composite key** — first-create flow когда client ещё не знает chain_op UUID.
6. **Resolved annotation response** — server JOIN'ит chain_operations, денормализует `(txHash, walletId, logIndex)` чтобы client matched в O(1).
7. **Cost basis override применяется в обоих pipelines** (`build.ts` и `cross_protocol.ts`) — у нас исторически два parallel-implementations.
